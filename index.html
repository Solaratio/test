Pertanyaan analisis dan diskusi

Apa fungsi GitHub dalam praktik ini?

GitHub berfungsi sebagai tempat menyimpan (repositori) file website, seperti index.html dan foto profil. Selain itu GitHub menyimpan riwayat perubahan file lewat Git, sehingga setiap revisi tercatat dan bisa dikembalikan. Dalam praktik ini repositori tersebut juga menjadi sumber yang diterbitkan oleh GitHub Pages menjadi website.

Mengapa website dapat diakses tanpa membuat web server sendiri?

Karena GitHub Pages menyediakan layanan hosting website statis. Server, jaringan, dan HTTPS dikelola oleh GitHub, sedangkan kita hanya mengunggah file HTML, CSS, dan gambar ke repositori. GitHub kemudian menyajikan file itu lewat alamat publik, misalnya namauser.github.io, sehingga kita tidak perlu menyewa, memasang, atau merawat server sendiri.

Apa hubungan GitHub Pages dengan Cloud Computing?

GitHub Pages adalah contoh pemanfaatan cloud computing. Sumber daya komputasi dan penyimpanan disediakan oleh penyedia layanan lewat internet, tersedia sesuai kebutuhan, dan bisa diakses dari mana saja tanpa kita memiliki perangkat kerasnya. Kapasitas dan ketersediaannya diatur oleh penyedia, jadi website tetap bisa dibuka banyak orang tanpa kita mengurus infrastrukturnya.

Apakah GitHub Pages termasuk SaaS, PaaS, atau IaaS? Jelaskan alasan Anda.

Menurut saya GitHub Pages paling tepat disebut PaaS. Kita membawa kode dan konten website, sedangkan penyedia mengelola server, sistem operasi, jaringan, dan lingkungan menjalankannya. Layanan ini bukan IaaS karena kita tidak menyewa atau mengatur mesin virtual, sistem operasi, maupun jaringan sendiri.

GitHub secara keseluruhan, yang diakses lewat browser untuk menyimpan dan mengelola kode, dapat dikategorikan sebagai SaaS. Pembagian ini bisa berbeda tergantung sudut pandang, jadi alasan di atas yang menjadi dasarnya.

Apa perbedaan file website di komputer lokal dan website yang dipublikasikan?

File di komputer lokal hanya ada di perangkat sendiri. Biasanya dibuka langsung dari folder lewat alamat seperti file:///, dan hanya kita yang bisa melihatnya. Website yang dipublikasikan disimpan di repositori GitHub dan disajikan oleh server GitHub lewat alamat publik, sehingga siapa pun yang punya tautannya bisa membukanya.

Perubahan di komputer lokal juga tidak langsung tampil di website. Perubahan itu baru muncul setelah di-commit dan di-push ke GitHub. Nama file di server bersifat sensitif huruf besar-kecil, jadi Sunraku.jpg dan sunraku.jpg dianggap berbeda.
